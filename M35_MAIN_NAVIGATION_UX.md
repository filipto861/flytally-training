# M35 — Main Navigation & Learner UX Overhaul

M35 simplifies the normal learner-facing navigation. It does not add or change aircraft training content.

## Navigation model

The previous stacked navigation model is retired:

- no top-level FLY/LEARN switch followed by a second changing submenu;
- no separate large configuration panel below navigation;
- no hidden global Aircraft link on mobile.

Each aircraft now exposes one persistent navigation surface:

- Overview and Progress are utility destinations;
- FLY always shows the currently published cockpit tools;
- LEARN always shows the currently published study/practice tools;
- the active module is highlighted directly;
- Quick Reference appears inside FLY when both performance and limitations are available;
- aircraft configuration is a compact selector inside the same navigation surface.

The menu remains data-driven: only learner capabilities backed by published aircraft content are shown.

## Global header

The product header is simplified to FlyTally Training, Aircraft library and compact account actions. Mobile retains the Aircraft library navigation on a second header row instead of hiding it.

## Boundaries

M35 changes navigation and presentation only. Published content, provenance, applicability, progress storage and governance remain unchanged.
