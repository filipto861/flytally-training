# M49 — Unified pilot pages

M49 completes the learner-facing hierarchy audit beyond Home, Fly, Systems and Procedures.

## Consistent hierarchy

All remaining deep pilot pages now use the same pattern:

- area (`Learn` or `Reference`),
- short task name,
- one concise purpose sentence,
- tool/content immediately after it.

Aircraft name and selected configuration remain visible in the aircraft navigation instead of being repeated inside every page title.

## Source and authority context

Source notes, disclaimers and authority boundaries remain available, but move into the same compact `Training & source notes` disclosure used elsewhere. No source-backed content is removed.

## Completion actions

The repeated explanatory completion row is reduced to a single `Mark complete` action. The full topic-specific description remains available as the button's accessible label. Completed/checking states remain explicit.

## Pages covered

Knowledge, Avionics, Flows, Performance, Limitations, Abnormal & Emergency, Quick Reference, Weight & Balance and Progress.

## Boundary

M49 changes presentation only. It does not alter aircraft data, calculation logic, publication rules, progress identity or database schema.
