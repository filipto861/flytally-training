# M47 — Pilot usability audit

M47 is a learner-facing information-hierarchy cleanup based on using the product as a pilot rather than as a content author.

## Audit findings

1. Too many simultaneous UI layers competed for attention: global header, aircraft rail, large page hero and content browser.
2. Aircraft Home did not always expose Reference as a first-class destination when Learn existed.
3. Desktop navigation visually dominated the content because of the dark full-height rail.
4. Mobile Systems and Procedures required navigating a secondary scrolling topic index before reaching the lesson content.
5. Repeated aircraft names, long explanatory copy and always-visible source/training notes pushed useful content down the page.

## M47 changes

- Home now exposes Fly, Learn and Reference independently when each capability exists.
- The desktop aircraft rail is lighter, narrower and less visually dominant while preserving the same four primary destinations.
- Mobile keeps the fixed four-way navigation but uses a compact aircraft/configuration row above content.
- Home, Learn and Reference cards are substantially shorter and task-oriented.
- Learner page titles and spacing are reduced so useful content starts higher on both desktop and mobile.
- Systems and Procedures replace their secondary mobile topic index with a single native topic selector.
- Training boundary and source-note content remains available in a compact disclosure instead of occupying the primary reading path.
- All changes remain publication-driven and aircraft-agnostic.
