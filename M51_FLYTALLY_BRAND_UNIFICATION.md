# M51 — FlyTally brand unification

M51 makes the Training product visibly part of the same FlyTally family as Logbook without adding new pilot-facing functionality.

## Brand lockup

The global header now uses the canonical FlyTally application mark already served by the Logbook production product at `fly-tally.com`, paired with a persistent `Training` product label and the `FlyTally` wordmark.

The wordmark intentionally remains visible on narrow mobile widths. Earlier navigation CSS hid the entire text lockup below 420 px, which is why the mobile header could degrade to an isolated `FT` placeholder-like mark.

## Visual language

Training continues to use the current Logbook light tokens introduced in M50. M51 tightens the shared header behavior:

- canonical FlyTally mark rather than an `FT` text placeholder
- persistent `FlyTally` wordmark on mobile and desktop
- compact `Training` eyebrow
- Logbook-compatible navy account action styling
- compact 60 px mobile header
- shared FlyTally mark also exposed as the page icon metadata

## Scope boundary

No aircraft content, checklist logic, performance logic, QRH procedure content, publication rules, database schema or applicability logic changes in M51.

The operational Fly surface remains limited to Checklist, Performance and Emergency.
