# M34 — Content Studio UX/UI Overhaul

M34 is a product-clarity milestone. It adds no new learner content and does not change the governed publication model.

## Workspace

Each aircraft now has a task-oriented administration workspace:

- Overview — attention state and next action
- Content — learner-facing modules and new-content creation
- Sources — source records, revisions and exact references
- Review — pending drafts/approvals and source-change reviews
- Settings — catalogue state, variants and advanced migration tools

The previous all-in-one Content Studio page is retired as the normal workflow.

## UI principles

- database identifiers and governance terminology stay out of the primary workflow;
- advanced migration/raw JSON controls are isolated in Settings;
- source-document hosting remains disabled;
- content status is presented as Draft, Approved, Live or Needs review;
- evidence and audit information uses progressive disclosure;
- structured content creation and editing remain the normal authoring path;
- the same workspace is aircraft-agnostic.

## Governance

M34 does not weaken governance. Existing immutable draft, approval, publication, provenance, source freshness and audit boundaries remain authoritative server-side.
