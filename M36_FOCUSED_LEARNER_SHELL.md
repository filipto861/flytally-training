# M36 — Focused Learner Shell

M36 reduces cognitive load in the normal learner-facing Training application. It changes navigation and presentation only; governed content, source authority, publication and progress persistence remain unchanged.

## Navigation model

- the global header stays minimal: FlyTally, Aircraft, account actions;
- each aircraft uses one contextual learner sidebar;
- Home and Progress are stable destinations;
- FLY and LEARN are mutually focused groups;
- only the currently active FLY or LEARN group expands into module links;
- inactive groups collapse to one entry point;
- module availability remains derived from actually published content domains;
- Quick Reference appears only when its required published domains exist;
- aircraft configuration remains a compact selector inside the aircraft navigation.

## Aircraft Home

Aircraft Home no longer duplicates the entire module catalogue. It presents only two primary decisions:

- FLY — cockpit tools;
- LEARN — study and practice.

Training-reference metadata is available through progressive disclosure rather than occupying primary screen space.

## Layout

On desktop the aircraft navigator is a sticky left sidebar and learner content occupies one focused content column. On smaller displays the same hierarchy becomes a compact top navigation without introducing a second navigation system.

## Boundaries

M36 does not add aircraft-specific branches, learner content, database schema, automatic source inference, or publication bypasses.
