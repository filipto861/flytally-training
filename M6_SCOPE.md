# M6 acceptance scope

- Quick Reference is source-backed and available through the generic content repository.
- FLY mode provides a compact simulator-side presentation without converting variable performance data into false fixed values.
- Knowledge questions are source-linked, provide immediate explanation and identify weak areas.
- Checklist completions, abnormal scenario completions and knowledge attempts emit one aircraft-agnostic progress event contract.
- Aircraft progress shows attempts, completed activities, recent practice and weak areas.
- M6 progress is browser-local; M7 changes persistence to account-backed storage without changing the learner-facing domain contract.
